    PonaMoji 沿用上传项目的 120 词根映射，用 Emoji 书写 Toki Pona。本地版使用电脑上的两个专用机器翻译模型，将中文先翻成英文，再翻成 Toki Pona，最后按原词典转写为 Emoji。

    翻译时会发生什么？

    默认的中文翻译在本机 Python 服务中运行中→英和英→Toki Pona 模型，不调用远程翻译 API，也不需要密钥。下载并加载模型后，可断网使用。输入后点击“翻译”，或按 Ctrl / ⌘ + Enter；使用 CPU 时可能需要等待。也可手动切换到浏览器规则模式，适用于已有简单句型。Toki Pona 与 Emoji 的转写仍在浏览器内完成。

    为什么翻回来会不一样？

    少量词根表达的概念很宽。例如 🐾 表示兽类动物，不能单独区分猫和狗；🍎 表示果蔬，并不专指苹果。目前没有反向翻译模型；Emoji → 中文仍使用规则生成近似释义。双模型也可能产生语义误差、错误语法或词典外词根，不能保证准确还原原意。词典外内容保留在 ⟦括号⟧ 中并提示，不会悄悄替换。可以展开英文和 Toki Pona 中间结果来查看每一步。

    怎样写出一个 PonaMoji 句子？

    一般主语后加 🔹（li），直接宾语前加 🎯（e）。主语单独是 🙋（mi）或 🫵（sina）时省略 li。修饰词通常放在名词后。建议 Emoji 之间保留空格；连写也能识别。Toki Pona 转写保留标点，旧词形沿用原项目的归一化约定。
